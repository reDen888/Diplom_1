# 🍔 Задание 1. Юнит-тесты для Stellar Burgers

## 📋 Описание проекта

Проект содержит комплексные юнит-тесты для сервиса **[Stellar Burgers](https://praktikum.yandex.ru)** - инновационного космического бургерного. Основная цель - обеспечить 100% покрытие тестами класса `Burger`, который отвечает за сборку космических бургеров и расчёт их стоимости.

В рамках дипломной работы по автоматизированному тестированию реализованы тесты с использованием современных инструментов тестирования: Mockito, JUnit 4, AssertJ и JaCoCo.

## 🚀 Технологический стек

- **Java 11** - основной язык разработки
- **JUnit 4.13.2** - фреймворк для модульного тестирования
- **Mockito 4.6.1** - библиотека для создания мок-объектов
- **AssertJ 3.24.2** - fluent assertions для читаемых проверок
- **JaCoCo 0.8.7** - инструмент для анализа покрытия кода
- **Maven** - система сборки проекта

## 🧪 Что тестируем

Класс `Burger` протестирован на **100% покрытие** ✅:

### 🍔 Основные функции бургера
- **Установка булочек** (`setBuns`) - выбор космической булочки
- **Добавление ингредиентов** (`addIngredient`) - наполнение бургера
- **Удаление ингредиентов** (`removeIngredient`) - коррекция рецепта
- **Перемещение ингредиентов** (`moveIngredient`) - изменение слоёв
- **Расчёт итоговой цены** (`getPrice`) - космический прайс-лист
- **Генерация чека** (`getReceipt`) - орбитальный чек

### 🎯 Особенности тестирования
- 🔄 **Параметризация** - тестирование различных комбинаций цен
- 🎭 **Моки и стабы** - изоляция тестируемого класса
- 📝 **Soft Assertions** - детальная проверка содержимого чека
- 🧪 **Различные сценарии** - тестирование边界 случаев (edge cases)
- 🌌 **Космические ингредиенты** - проверка соусов и начинок

## 🚀 Как запустить

1. Запустить тесты с помощью Maven:

```bash
mvn clean test
```

2. Сгенерировать отчет о покрытии кода:

```bash
mvn jacoco:report
```
Отчет будет доступен по пути: target/site/jacoco/index.html
